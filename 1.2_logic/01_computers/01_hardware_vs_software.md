# Part 1 – Hardware vs Software

## Explain Hardware
Hardware refers to the physical parts of a computer or electronic device that you can see and touch.

Examples of Hardware
CPU (Central Processing Unit): The "brain" of the computer that processes instructions.
Monitor: Displays visual output.
Keyboard: Used to enter text and commands.
Mouse: Controls the cursor on the screen.
RAM (Random Access Memory): Temporarily stores data while programs are running.
Hard Drive / SSD: Stores files, programs, and the operating system.
Printer: Produces physical copies of documents and images.
Motherboard: Connects and allows communication between all hardware components.

Types of Hardware
Input Devices: Keyboard, mouse, scanner, microphone.
Output Devices: Monitor, printer, speakers.
Storage Devices: Hard drives, SSDs, USB drives.
Processing Devices: CPU, GPU.
Communication Devices: Network card, modem, router.
Simple Definition

Hardware is the collection of all physical components of a computer system that work together to process, store, and display information.

For example, when you type a document in Microsoft Word:

The keyboard (hardware) sends your input.
The CPU (hardware) processes it.
The monitor (hardware) displays it.
Word itself is software.


## Explain Software
Software is a collection of programs, instructions, and data that tell a computer how to perform specific tasks. Unlike hardware, software cannot be physically touched.

Examples of Software
Operating Systems: Windows, macOS, Linux, Android
Application Software: Microsoft Word, Excel, PowerPoint, Google Chrome
Media Software: VLC Media Player, Spotify
Games: Minecraft, FIFA, Fortnite
Security Software: Antivirus programs
Types of Software
1. System Software

Manages and controls the computer's hardware and provides a platform for other software.

Operating Systems (Windows, Linux)
Device Drivers
Utility Programs
2. Application Software

Helps users perform specific tasks.

Word Processors (Microsoft Word)
Spreadsheets (Microsoft Excel)
Web Browsers (Chrome, Edge)
3. Programming Software

Used by developers to create other software.

Compilers
Interpreters
Code Editors (Visual Studio Code)

How Software and Hardware Work Together

When you open Microsoft Word:

The software (Word) receives your commands.
The CPU (hardware) processes those commands.
The RAM (hardware) temporarily stores the data.
The monitor (hardware) displays the document.

## How Do Hardware and Software Interact?
Hardware and software work together to make a computer function.

Think of it like this:

Hardware = the physical parts (CPU, keyboard, monitor, memory).
Software = the instructions that tell the hardware what to do.
How They Interact

When you perform a task, software sends instructions to the hardware, and the hardware carries out those instructions.

Example: Typing a Document
You press a key on the keyboard (hardware).
The operating system and word processor (software) detect the key press.
The CPU (hardware) processes the input.
The RAM (hardware) temporarily stores the data.
The monitor (hardware) displays the letter on the screen.
When you save the file, the software tells the hard drive/SSD (hardware) to store it.
